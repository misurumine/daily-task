# Daily Task Live

หน้าดูไลฟ์สำหรับลูกค้าของ **Daily Task** — ดูได้เฉพาะหน้าต่างเกมที่กำหนด พร้อมส่งข้อความ / Emoji / สติกเกอร์ / GIF / รูป
ไปเด้งบนจอผู้ไลฟ์แบบเรียลไทม์ (ไม่มีการเก็บประวัติ)

> **⚠️ กฎเหล็ก (สำหรับ AI / ผู้พัฒนา):**
> 1. ก่อน สร้าง / ลบ / แก้ไข ไฟล์ ต้องแจ้งรายละเอียดผู้ใช้ก่อน และรอให้ผู้ใช้พิมพ์ว่า "ยืนยัน" เท่านั้น
> 2. ไม่รู้หรือไม่แน่ใจ ต้องถามผู้ใช้ ห้ามเดา
> 3. แก้โปรโตคอลฝั่งเว็บต้องแก้ฝั่ง DailyTaskApp ให้ตรงกันเสมอ — ยึดตาม [`PROTOCOL.md`](PROTOCOL.md)

## โครงสร้าง

```
public/
  watch.html          หน้าดูไลฟ์ (ลิงก์จริง: watch.html#<token>)
  index.html          หน้าแรก (ส่งต่อไป watch.html ถ้ามี token)
  js/crypto.js        token → topic + กุญแจ AES-GCM (HKDF-SHA256)
  js/signal.js        ช่องสัญญาณ MQTT แบบเข้ารหัส (broker สาธารณะ, สำรองกันอัตโนมัติ)
  js/watch.js         WebRTC รับภาพ/เสียง, ปรับคุณภาพ/เสียง, แชท, สติกเกอร์, GIF
  css/watch.css
  stickers/           สติกเกอร์ชุดของร้าน (ดู stickers/README.md)
.github/workflows/deploy.yml   deploy โฟลเดอร์ public/ ขึ้น GitHub Pages อัตโนมัติเมื่อ push
PROTOCOL.md           ข้อตกลงการสื่อสารกับ DailyTaskApp
```

## การทำงาน

1. ลูกค้าล็อกอิน → DailyTaskApp สร้าง token สุ่ม 128-bit แล้วส่งลิงก์เข้า Discord Thread ส่วนตัวของลูกค้า
2. หน้าเว็บใช้ token สร้าง topic + กุญแจ แล้วคุยกับ DailyTaskApp ผ่าน MQTT แบบเข้ารหัสเพื่อเริ่ม WebRTC
3. ภาพ/เสียง และแชท วิ่งตรงระหว่างเครื่อง (P2P) — ไม่ผ่าน server และไม่เก็บประวัติ
4. ลูกค้าล็อกเอาท์ → token ถูกยกเลิก ลิงก์ใช้ไม่ได้อีก

## ข้อจำกัด

- ใช้ STUN ฟรีเท่านั้น (ไม่มี TURN) — เครือข่ายบางแบบ (เช่นเน็ตมือถือบางเจ้า) อาจเชื่อมต่อไม่ได้
- อัปโหลดของผู้ไลฟ์ ~2–6 Mbps ต่อผู้ชม 1 คน
